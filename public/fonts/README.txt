站点内置字体（全部 SIL Open Font License 1.1，许可证原文见同目录 OFL.txt）

- rv-sans.woff2 / rv-serif.woff2
  由 Noto Sans SC / Noto Serif SC（Google Noto 项目）子集化而来，
  只保留本应用实际用到的字符。

- rv-hand.woff2
  手写体：以 Bad Script（Gaslight，OFL）为基础，改名为「RV Hand」。
  字母「т」参照 Bad Script「п」的起笔、圆拱、笔画粗细和右倾，
  重画为双拱的 m 形；字高参照未修改的「п」，源轮廓见 glyph/t-new.svg。
  重建：python scripts/glyph.py import glyph/t-new.svg --install
  字母「м」保留此前基于 Caveat（Impallari Type，OFL）拉丁小写 m
  的圆角、减细轮廓。
  用途：俄语手写体认读练习。

字体文件仅用于本站展示，不单独分发。
