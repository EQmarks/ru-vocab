# 任务：重画俄语手写体小写字母「т」

你是一个字体/字形设计师。请基于下面给出的当前字形，重新设计俄语手写体小写字母 **т**（手写时写成英文 m 的形状）。

## 背景

- 这是一个俄语背单词网站用的手写体，学习者用它认俄语连笔字。
- 字体基础是 Bad Script：笔画细、整体略向右倾、有连笔感。
- 当前字形已经接近可用，但有两个小毛病：**拱顶有尖角**、**中间/底部偶尔冒出小尖**，放在词里不够干净。

## 你要输出的东西

只输出 SVG 的 **path 元素**，不要解释、不要 markdown、不要 transform、不要 style、不要多个 path 叠在一起。

如果愿意，请给 **3 个候选版本**，每行一个，用 A/B/C 开头：

A: <path d="..." />
B: <path d="..." />
C: <path d="..." />

三个版本可以是：
- A 保守微调：基本保留当前轮廓，只把尖角磨圆；
- B 更圆润：拱顶更饱满、笔画更柔和；
- C 更接近手写连笔：起笔/收笔更像一笔写下来。

## 几何规格（重要）

坐标系：**y 轴向下**，基线在 **y = 500**，x 从 0 开始（画布约 760 × 560）。

- 整体宽度约 **680**，高度约 **420**（小写字母 x-height 的高度）；
- 笔画粗细约 **50–55**（不要突然变粗/变细）；
- 两个拱顶：**左右等高**（顶部大约 y = 80）、**宽度相近**（各约 300 宽），拱顶要**圆滑**，不要尖角、毛刺、小勾；
- 中间谷底：圆滑的 U/V 形，最低点大约 y = 300；**不要出现任何小尖尖、小凸起、交叉的线头**；
- 底部：左右两个落脚点都落在 **y ≈ 498–500**，**平齐**，收笔圆润，不要横向的小尾巴；
- 整体保持手写的**轻微右倾**（约 8–10°），和 Bad Script 的斜度一致，不要变成印刷体或直立的 m；
- 起笔自然，不要高高的小勾；笔画可以有一点粗细变化，但要均匀。

- 放大看：两个拱顶是否一样高、一样宽？
- 中间是否还有尖刺/小凸起？
- 底部两个脚是否在同一水平线、没有小尾巴？
- 把它读成单词：привет、тетрадь、томат —— 看起来是否像自然的连笔 m？
