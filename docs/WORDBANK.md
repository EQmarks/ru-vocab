# 词库：《东方大学俄语（新版）》第 1 册

## 来源

- 教材：东方大学俄语（新版）学生用书 1，2020 年版（外研社），用户提供的 PDF
- 词表底稿：Kienyew/Russian-Chinese-Vocabulary 中由教材单词 doc 解析出的 JSON（1–4 册，本词库取第 1 册）
- 重音：ruaccent 的重音词典（约 319 万条），个别专名手工修正
- 分课：以教材词表原文每个词条末尾的课次（1–18）为准，修正了原 JSON 里分错课的词（例如 поступать 应为第 16 课，之前误放在第 1 课）

## 规模

18 课 / 854 词。每课词数不等（第 8 课 14 词，第 7 课 77 词），按教材课次组织。

## 做了哪些检查

- 拼写：854 个词全部过 pymorphy3 词典；除专有名词、复合词 русско-китайский 外均可解析
- 截断词修复：мний → зимний、дка → соседка、д → велосипед（原 doc 解析时被截断）
- 粘在一起的短语拆分：досвидания → до свидания、потомучто → потому что、другдруга → друг друга 等 16 处
- 重音：用重音词典逐词标注；Баку 等专名手工修正；含 ё 的词按规则不加重音符
- 释义：清掉了页码/邻词混入括号的污染（如「参加（16потом…」），统一中文分号
- 交叉核对：用教材后的 СЛОВАРЬ 生词表页扫描 OCR 做模糊比对，627 个词能在印刷词表中找到对应

## 已知不确定

- 扫描 OCR 的俄文识别质量一般（字母/重音易错），所以只做了模糊比对，未逐词人工核对全部 854 条
- 少数词的释义可能带原 doc 的偏差；若发现某词释义/重音不对，把词发我即可单独修
- 旧的自建 720 词词库保留在 data-src/units-legacy/，需要切回可以恢复

## 文件与重建

- 数据源：data-src/units/01-lesson1.json … 18-lesson18.json
- 构建：npm run build → public/data/words.json
- 音频：npm run audio → public/audio/*.mp3 + index.json
